## 📌 1. 기술 스택 및 개발 환경 (Tech Stack)

- **Languages & Core**: TypeScript, HTML5, CSS3
- **Framework**: Next.js (App Router)
- **Styling**: Tailwind CSS
- **State Management**: TanStack Query, Zustand
- **DX / Test**: Storybook, Axios, Playwright
- **Code Quality**: ESLint, Prettier
- **Monitoring**: Lighthouse
- **Act**: Git & GitHub, AWS, gemini, linear, notion, discord

### 로컬 실행 준비

- 실행 전에 `cp .env.example .env.local`로 환경 변수 파일을 만들고, 팀에서 공유한 값(`NEXT_PUBLIC_API_BASE_URL` 등)을 채운 뒤 서버를 시작합니다.
- `NEXT_PUBLIC_*` 값은 서버 시작/빌드 시점에 주입되므로 값을 바꾸면 dev 서버를 재시작해야 합니다.
